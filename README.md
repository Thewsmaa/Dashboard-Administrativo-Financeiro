# Dashboard Administrativo e Financeiro — Excel & Power BI

Projeto de análise de dados desenvolvido com Excel e Power BI,
com foco no acompanhamento financeiro e administrativo de uma
empresa fictícia.

O projeto tem como objetivo transformar dados operacionais em
informações para apoiar a tomada de decisões.

## 🎯 Objetivo

Desenvolver uma solução de análise administrativa e financeira
capaz de acompanhar:

- Faturamento
- Pagamentos
- Valores em aberto
- Valores em atraso
- Desempenho por departamento
- Desempenho por cliente
- Evolução mensal da receita
- Formas de pagamento
- Categorias de operação

- ## 🛠️ Ferramentas

- Microsoft Excel
- Power Query
- Power BI
- DAX
- Git
- GitHub

- ## 📚 Conceitos aplicados

- Tratamento e limpeza de dados
- Modelagem de dados
- Tabelas Dinâmicas
- KPIs
- Medidas DAX
- Dimensão calendário
- Relacionamentos
- Análise temporal
- Data Visualization
- Storytelling com dados

- ## 🔄 Processo

### 1. Preparação dos dados

Os dados foram inicialmente estruturados no Excel,
com organização dos registros e criação da tabela de dados.

### 2. Análise no Excel

Foram utilizadas fórmulas, Tabelas Dinâmicas e gráficos
para realizar uma primeira análise exploratória.

### 3. Tratamento no Power Query

Os dados foram importados para o Power BI e passaram por
processos de limpeza, padronização e transformação.

### 4. Modelagem

Foi criada uma dimensão calendário e estabelecido o
relacionamento entre a tabela de dados e o calendário.

### 5. DAX

Foram desenvolvidas medidas para cálculo de:

- Receita Total
- Valor Pago
- Valor em Aberto
- Valor em Atraso
- Ticket Médio
- Taxa de Inadimplência
- Crescimento Mensal

## 📊 Principais KPIs

- | Indicador | Descrição |
|---|---|
| Receita Total | Valor total das operações |
| Valor Pago | Total efetivamente pago |
| Valor em Aberto | Valores ainda não pagos |
| Valor em Atraso | Valores associados a operações atrasadas |
| Ticket Médio | Receita média por operação |
| Inadimplência | Percentual de operações em atraso |
| Clientes Ativos | Quantidade de clientes distintos |
